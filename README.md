# SubLoom AI MVP

一个手机/电脑浏览器都能使用的视频本地化网站原型。

## 已实现
1. **硬字幕翻译**
   - 读取视频画面底部已经烧录的字幕
   - OCR 恢复时间轴
   - 自动翻译
   - 可覆盖原字幕，或保留原字幕并在上方加译文
   - 导出 MP4 + SRT

2. **语音 → 翻译字幕**
   - faster-whisper 识别视频语音
   - 翻译为目标语言
   - 烧录新字幕
   - 导出 MP4 + SRT

3. **语音 + 字幕完整本地化**
   - 语音识别
   - 翻译
   - gTTS 生成目标语言配音
   - 时间轴铺设
   - 新字幕 + 新音轨合成到 MP4

## 当前 MVP 的已知边界
- 硬字幕 OCR 默认扫描视频底部区域。复杂字幕位置/动画字幕建议后续加可视化框选和检测模型。
- “保留背景音乐”目前采用降低原音轨音量再混合，不是真正的人声分离。商业版建议加入 Demucs/UVR。
- gTTS 是 MVP 配音。商业版应替换为高质量 TTS API，并增加声音选择、语速和情绪。
- deep-translator 适合快速 MVP，商业化后建议换成稳定、可计费的正式翻译 API。
- faster-whisper 首次运行需要下载模型；部署平台需要足够内存/磁盘。
- 上传视频会临时存放在 `work/`。正式上线必须增加自动删除任务、对象存储、隐私政策和访问控制。

## 本地启动
```bash
docker build -t subloom .
docker run --rm -p 8000:8000 subloom
```
打开 `http://localhost:8000`

## 部署
项目根目录包含 Dockerfile。Render / Railway 都可以从 GitHub 仓库直接读取 Dockerfile 构建。
